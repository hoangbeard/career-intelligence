Location: remote (Vietnam), occasional travel to Singapore
Salary: not disclosed

Acme Fintech runs a payment gateway for merchants in Southeast Asia.

- Own the AWS security baseline across 25 accounts.
- Build detection and response automation (GuardDuty, Security Hub, Lambda).
- Review Terraform changes for security.
- Lead cloud incident response.

## Requirements

- 5+ years in cloud or infrastructure security.
- Deep AWS IAM and organizations knowledge.
- Terraform.
- Incident response experience.
- PCI DSS exposure is a plus.
