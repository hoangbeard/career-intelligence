# Application Security Lead — Globex Cloud (fictional)

Location: Ho Chi Minh City, hybrid (2 days in office)
Salary: USD 5,500 – 7,000 per month gross
Contact: careers@globex.example

Globex Cloud builds an API management platform used by 2,000 companies. We are
looking for an Application Security Lead to own our secure development
programme across 12 product teams.

## What you will do

- Own the application security programme for 12 product teams.
- Run threat modelling for new services and major changes.
- Build and tune security checks in CI/CD (SAST, SCA, secrets, container scanning).
- Lead secure code reviews for high-risk changes.
- Grow and lead a security champions network.
- Coordinate the bug bounty programme and triage reports.
- Mentor 2 application security engineers.
- Work with compliance on SOC 2 evidence (about 15% of the time).

## Must have

- 6+ years in software engineering or security, 3+ in application security.
- Hands-on threat modelling (STRIDE or similar).
- Experience building security gates in CI/CD.
- Strong knowledge of OWASP Top 10 and ASVS.
- Secure code review in at least one of Go, Java or TypeScript.
- Experience leading or mentoring engineers.

## Nice to have

- AWS and Kubernetes security.
- Bug bounty programme management.
- SOC 2 experience.

## Benefits

- 13th-month salary, private health insurance, USD 1,000 yearly learning budget.
